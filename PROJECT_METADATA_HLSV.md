# Metadados do projeto — LDEA

## Descrição
Projeto associado à LDEA que apresenta cursos online gratuitos para jovens e iniciativas de acesso ao conhecimento em tecnologia e programação. O README também anuncia uma plataforma de música, treinamento de segurança digital, gerador de senhas, boletim de segurança e ferramenta antiphishing. Consulte o código para confirmar quais desses componentes estão implementados e disponíveis; não trate senhas geradas como impossíveis de adivinhar ou hackear.
